# 🎮 Game Library Manager

A terminal-based Python application for managing a personal game library.

## ✨ Features

- Add games to your library
- View all games
- Mark games as completed
- Update played hours
- Delete games
- View library statistics
- Save and load games using JSON
- Persistent data between program restarts
- Input validation

## 🐍 Concepts Used

- Python OOP
- Classes and objects
- Attributes and methods
- Lists
- Loops
- Functions
- Dictionaries
- JSON
- File handling
- Try / Except
- List comprehensions

## 📊 Statistics

The program can display:

- Total games
- Total hours played
- Number of completed games

## 💾 Data Storage

Games are stored locally inside `jocuri.json`.

The JSON file is ignored by Git, so each user can have their own game library.
